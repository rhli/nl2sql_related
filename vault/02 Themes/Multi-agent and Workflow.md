# Multi-agent and Workflow

把分解从 prompt 升级成角色：生成、选择、修复、检索各由一个 agent 负责。MAC-SQL 定了 Selector/Decomposer/Refiner 原型，CHASE-SQL 把多路径推理和偏好选择做成测试时扩展，DeepEye-SQL 进一步工程化。
